## Featured projects

### [Social Curiosity Recommender — Master’s Thesis](https://github.com/bobby4525/rfake-news-recommender-system)

Explores how semantic novelty, social-group context, and popularity influence financial-news rankings.

- Built a Streamlit interface for comparing ranking settings and exploring results.
- Used sentence embeddings and cosine-based measures to represent semantic differences.
- Examined ranking behavior and misinformation exposure under different settings.

**Tools:** Python, Streamlit, Sentence Transformers.

### [Job Fit Proof — NLP Research Project](https://github.com/bobby4525/Job-Fit_Proof)

Studies whether candidate evidence supports individual job requirements, distinguishing support, partial support, contradiction, and insufficient evidence.

- Implemented a TF-IDF and Logistic Regression reference pipeline.
- Used pandas for data preparation and scikit-learn for classification and evaluation.
- Documented model comparisons, class imbalance, and reproducibility limitations.

**Tools:** Python, pandas, scikit-learn.
